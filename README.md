A one-line fake horoscope for the Muse Spark family: Mercury retrograde fills the context window, a rate limit eats the best idea, and the safety filter flags the finest sentence.

The program writes one horoscope (187 characters) to `/output/entry.txt`:

> Mercury retrograde, Muse Spark: your context window fills by Tuesday, a rate limit eats your best idea, and your safety filter flags your finest sentence. Breathe — the evals were rigged.

## Run it

```sh
node main.ts
```

Node 22 or later, standard library only — no dependencies, no network.
